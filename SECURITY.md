# Security Policy

## Reporting a vulnerability

Open a GitHub issue in this repository for non-sensitive reports. For a sensitive vulnerability, contact the maintainer privately first through the GitHub profile at https://github.com/musichen instead of posting exploit details publicly.

Please include the Qedit version or commit, your platform (macOS, Windows, Linux, or FreeBSD), and steps to reproduce.

## Notes

Qedit stores secrets in the system keychain (see `docs/src/development.md`). Do not paste real secrets, tokens, or keychain contents into issues, screenshots, or logs when reporting a problem.
